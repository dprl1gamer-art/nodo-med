# NODO MED — Tecnología hospitalaria

Repositorio del prototipo académico **NODO MED**, una interfaz web demostrativa para explorar la integración de sensores, software y sistemas hospitalarios conectados.

## Contenido

- `index.html`: estructura principal de la aplicación.
- `styles.css`: estilos, diseño adaptable y componentes visuales.
- `app.js`: navegación, secciones y lógica de interacción de la interfaz.

## Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto.
3. Abre `index.html` en un navegador.

También puedes usar la extensión **Live Server** de Visual Studio Code y seleccionar **Open with Live Server** sobre `index.html`.

> Algunas imágenes y fuentes se cargan desde servicios externos, por lo que requieren conexión a Internet.

## Publicar en GitHub

1. Inicia sesión en [GitHub](https://github.com/).
2. Crea un repositorio nuevo llamado `nodo-med`.
3. No marques las opciones para agregar README, `.gitignore` o licencia (ya están incluidos aquí).
4. En la terminal, dentro de esta carpeta, ejecuta:

```bash
git remote add origin https://github.com/TU-USUARIO/nodo-med.git
git branch -M main
git push -u origin main
```

Reemplaza `TU-USUARIO` por tu nombre de usuario de GitHub.

## Aviso

Este proyecto es una demostración académica. No está validado para diagnóstico, monitoreo clínico ni toma de decisiones médicas.
